# CNV Analysis with GenomeStudio and RStudio Server

This repository provides a Docker-based workflow for CNV analysis using:

- **GenomeStudio** for SNP-array processing
- **RStudio Server** for downstream CNV analysis and visualization

---

## 1. Prepare the experiment folder

Create a folder for your experiment.

This folder will be referred to as:

```bash
CNV_ROOT
```

For example:

```bash
CNV_ROOT=/path/to/your/experiment_folder
```

> **Note:** `CNV_ROOT` must point to your experiment folder.

---

## 2. Add the GenomeStudio startup script

Place the GenomeStudio startup script inside the experiment folder:

- `start-genomestudio.sh` for macOS / Linux
- `start-genomestudio.bat` for Windows

This script is used to start the GenomeStudio Docker container.

---

## 3. Create the input folder structure

Inside the experiment folder, create:

```text
scratch/
└── input_files/
    └── genomestudio/
```

The `scratch` folder will be mounted inside the Docker containers.

Place the files required by GenomeStudio inside:

```text
scratch/input_files/genomestudio/
```

Files that are required later by the RStudio pipeline, such as the exported `.xml` files and the sample sheet, should be kept inside:

```text
scratch/input_files/
```

---

## 4. Files required by GenomeStudio

GenomeStudio requires the following files.

### Sample sheet

A valid:

```text
samplesheet.csv
```

### Raw data files

The SNP-array files obtained from **Life & Brain**.

### Manifest and cluster files

If your experiment uses a manifest different from the default one, place the corresponding files inside:

```text
scratch/input_files/genomestudio/
```

Required file types are:

```text
.egt
.bpm
```

The default manifest files are already included in the GenomeStudio Docker image:

```text
GSAMD_24v3-0_A1-LAB-2235HiQ-Samples.egt
GSAMD-24v3-0-EA_20034606_A1.bpm
```

---

## 5. Create the output folder

Inside the experiment folder, create:

```text
Output/
```

This folder will be mounted inside the Docker containers and will be used to store output files generated by both:

- GenomeStudio
- RStudio / CNV analysis pipeline

Your experiment folder should therefore look approximately like this:

```text
experiment_folder/
├── start-genomestudio.sh
├── Output/
└── scratch/
    └── input_files/
        └── genomestudio/
```

# Running the Docker containers

## Step 1 — Start Docker

Make sure Docker Desktop or the Docker daemon is running.

---

## Step 2 — Open a terminal

Open a terminal window.

---

## Step 3 — Define the experiment folder

Set `CNV_ROOT` to your experiment folder.

Example:

```bash
CNV_ROOT="/Users/elisabalmaselisabalmas/Library/CloudStorage/GoogleDrive-elisa.balmas@unito.it/Shared drives/MBC-HEDGe_EB/001_vario/softwares/CNV_analysis_docker"
```

Then move into the folder:

```bash
cd "$CNV_ROOT"
```

---

## Step 4 — Start GenomeStudio

Run:

```bash
sh start-genomestudio.sh --port 8890
```

GenomeStudio will be available at:

```text
http://localhost:8890/lab
```

---

## Step 5 — Start RStudio Server

Run:

```bash
docker run -d --rm \
  --platform linux/amd64 \
  --name cnv-rstudio-test \
  -p 127.0.0.1:8080:8787 \
  -e PASSWORD='test-password' \
  -v "$CNV_ROOT/Output:/home/rstudio/project/Output" \
  -v "$CNV_ROOT/scratch:/home/rstudio/project/scratch" \
  hedgelab/cnv-rstudio:2.1
```

RStudio Server will be available at:

```text
http://localhost:8080
```

Login credentials:

```text
Username: rstudio
Password: test-password
```

The password corresponds to the value specified here:

```bash
-e PASSWORD='test-password'
```

If you change this value, use the new password to log in.

# GenomeStudio analysis

Open GenomeStudio in your browser:

```text
http://localhost:8890/lab
```

Run the GenomeStudio pipeline by following **SOP 22**, which is also available in the Docker folder.

After completing the GenomeStudio analysis, export the required `.xml` file or files.

Save the exported files inside:

```text
scratch/input_files/
```

Keep the corresponding:

```text
samplesheet.csv
```

in the same input folder.

---

# RStudio CNV analysis

Open RStudio Server:

```text
http://localhost:8080
```

Set the working directory as described in the SOP.

The mounted project directory is:

```text
/home/rstudio/project/
```

and contains:

```text
/home/rstudio/project/Output
/home/rstudio/project/scratch
```

---

## Single XML file

If the GenomeStudio analysis generated a single `.xml` file, run:

```text
run_CNV_analysis.Rmd
```

---

## Multiple XML files

If the GenomeStudio analysis generated multiple `.xml` files, run:

```text
run_CNV_analysis_multi_XML.Rmd
```

---

# Visualization

sample_id

## Startup scripts and folder structure clarifications

- Use `start-genomestudio.sh` on **macOS / Linux** and `start-genomestudio.bat` on **Windows**. The shell commands above use macOS / Linux syntax.
- Keep GenomeStudio-specific inputs in `scratch/input_files/genomestudio/`.
- Keep the exported XML file(s) and the corresponding `samplesheet.csv` for the R pipeline in `scratch/input_files/`.
- Create both `scratch/` and `Output/` inside the experiment folder identified by `CNV_ROOT`.
